    Búsqueda Global — Localiza una dirección IP (parcial o completa) en todos los recursos del sistema al mismo tiempo: VIPs, nodos LTM, Self IPs y SNATs.

    ¿Cómo usarla?

    • Escribe una IP completa (10.10.1.5) o un fragmento (10.10.1) para ver todas las coincidencias.
    • La búsqueda es de coincidencia parcial: 107.10.1 devolverá 107.10.1.2, 107.10.1.3, etc.
    • Se muestran las primeras 25 coincidencias entre todos los tipos de recurso.

    Tipos de recursos buscados

    • VIP Direcciones de destino de servidores virtuales.
    • LTM Node Nodos de los pools de balanceo.
    • Self IP Direcciones propias del equipo F5.
    • SNAT Traducciones de dirección de origen.
    Útil para identificar a qué servicio o equipo pertenece una IP desconocida.
